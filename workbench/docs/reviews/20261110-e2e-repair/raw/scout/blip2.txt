## The five special points, stated plainly

- **Image transform at evaluation:** all five build `data_utils.targetpad_transform(1.25, 224)` in their replay shell (`airknow.py:174`, `conesep.py:164`, `habit.py:151`, `intent.py:151`, `hint.py:184`). That is the repo’s own function: `TargetPad(1.25)` → `Resize(224, BICUBIC)` → `CenterCrop(224)` → RGB → `ToTensor` → CLIP mean/std (`data_utils.py:92-105`). `squarepad_transform` exists in every repo but no path selects it; no CLIP default transform is used.
- **LAVIS text processor:** config is `configs/models/blip2/blip2_pretrain.yaml` in every case, selected from the model class’s `PRETRAINED_MODEL_CONFIG_DICT`, loaded through `OmegaConf.load` + `load_preprocess(cfg.preprocess)` (`lavis_processors.py:216-217`) rather than `load_model_and_preprocess`. **No `max_length` is set on the processor** — `BlipCaptionProcessor(prompt="", max_words=50)` truncates at 50 words. `max_length=32` belongs to the model’s internal BERT tokenizer, not the LAVIS processor.
- **Caption join:** identical string in all five: `"{} and {}".format(self.correct_text(captions[0], correction_dict), self.correct_text(captions[1], correction_dict))`.
- **`-10e10` on the FashionIQ path:** yes for all five. AirKnow `test_BLIP2.py:151`, ConeSep `test.py:68`, HABIT `test.py:151`, INTENT `test.py:150`, HINT `test.py:83` — unconditional in the non-`fashion200k` branch, written before `argsort`.
- **Recall arithmetic:** hits / `len(nn_result)` (one row per query), **multiplied by 100**, at AirKnow `:174`, ConeSep `:81`, HABIT `:174`, INTENT `:173`, HINT `:106`.
