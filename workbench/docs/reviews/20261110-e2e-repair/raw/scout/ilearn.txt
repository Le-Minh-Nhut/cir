## Cross-model notes the lines imply

- **Transform asymmetry is not shared.** ENCODER and PAIR apply `transform[0]` (stochastic `preprocess_train`) to query images and `transform[1]` (`preprocess_val`) to gallery images — that is why their replays wrap dataset construction in `seeded_dataset_construction` (`replay/encoder.py:309`, `replay/pair.py:177`). LIMN's *test* path sends both query and gallery through `transform[1]` (`datasets.py:151,153,166`), so LIMN's query population is deterministic; its train path is the one using `transform[0]`. TG-CIR and CLVC-Net have a single transform, so there is no stage distinction to report.
- **Caption pipeline splits into two families.** ENCODER/PAIR/TG-CIR/LIMN all use `correct_text` → `concat_text` with `" and "` and apply the per-category `correction_dict` by exact token lookup. CLVC-Net has no correction dictionary at all and uses `<BOS> … <AND> … <EOS>` with `SimpleVocab`, which *deletes* punctuation (`maketrans({key: None …})`) rather than mapping it to a space — a different normalization, not a parameterization of the same one.
- **Reference handling is identical in mechanism across all five:** mask the reference score to `-10e10` in place before a descending `argsort`, never physically remove it. Lines: `test.py:68` (ENCODER), `:68` (PAIR), `:135` (CLVC-Net), `:67` (TG-CIR), `:82` (LIMN).
- **Recall arithmetic and units are identical:** percent, `100 * hits / len(nn_result)`, K ∈ {1,10,50}, denominator = that category's query count (not gallery size), top-50 candidate list. Macro is *not* native to any of these five; it is workbench-added equal-weight category averaging in `replay/common.py:310-320`, with `macro_mean = (macro_r10 + macro_r50) / 2`.
- **ENCODER's `datasets.py:64` default is a double default:** `FashionIQ.__init__(..., split='val-split')` at `:64` is only the fallback; the actual value comes from `evaluate_model.py:15` (`--fashioniq_split` default `'val-split'`) threaded through `:43`. The replay bypasses both and passes `split="val-split"` explicitly (`replay/encoder.py:310`). PAIR has the same shape (`datasets.py:23` + `train.py:29`), with the extra caveat that PAIR's launcher default `--dataset` is `shoes`, not FashionIQ.
- **TG-CIR has no runnable path in this workbench:** `replay/tgcir.py` is preflight-only and returns blockers unconditionally (checkpoint mapping, missing author SHA, unverified ViT-B/16 asset), so its source lines above are static evidence only — no replay ever reaches `test.py:67`.
