### Đường bấm tới đúng workflow nghiên cứu (protocol `circus_fashioniq_release_v1`, subset `full`)

Deep link ngắn nhất (bỏ qua bước chọn subset, vì mặc định là `sf` — xem §4.2):

```
http://127.0.0.1:5173/?area=samples&view=explorer&protocol=circus_fashioniq_release_v1&subset=full
```

Bấm tay từ trang chủ thì 3 bước (bước 2 là bước thừa do mặc định `sf`):

1. Menu trái → **Khám phá mẫu** (`area=samples`).
2. Ô **Subset** (`[data-testid=subset-select]`) → đổi `Shortcut-Free (SF)` → **`Full`**.
3. Ô **Lượt chọn** (`#run-select`) → chọn run. Nhãn nay có dạng
   `hint / fashioniq · f461f391 · Top-K 100` (mô hình / checkpoint · 8 ký tự run id · độ sâu export),
   nên chọn được **đúng** run có ứng viên mà không phải thử.

Đi thẳng vào một query đã chấm (dùng làm mốc đối chiếu — hạng MM **98** trên HINT, **65** trên TME):

